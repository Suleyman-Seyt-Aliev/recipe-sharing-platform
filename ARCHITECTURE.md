# Архитектура платформы для шеринга рецептов и планирования меню (Вариант 24)

## 1. Назначение системы
Платформа позволяет кулинарам публиковать рецепты, а шеф-редакторам — модерировать их. Ключевая функция: автоматический пересчёт ингредиентов при изменении количества порций и формирование общего списка покупок на выбранные блюда.

## 2. Ролевая модель и Use Cases

**Роли пользователей:**
* **Кулинар (Author)** — создаёт и управляет своими рецептами.
* **Шеф-редактор (Editor)** — проверяет и публикует рецепты.

**Сценарии использования (Use Cases):**

**Кулинар:**
* Регистрация / Вход в систему.
* Создание нового рецепта (название, описание, фото, категория).
* Добавление ингредиентов с указанием количества.
* Редактирование и удаление своих рецептов.
* Просмотр списка своих рецептов.

**Шеф-редактор:**
* Вход в систему.
* Просмотр рецептов, ожидающих модерации (статус "На проверке").
* Публикация рецепта (статус "Опубликован").
* Отклонение рецепта с указанием причины.

**Система (общие функции):**
* Изменение количества порций в рецепте с автоматическим пересчётом ингредиентов.
* Генерация сводного списка покупок по выбранным рецептам.
