# Recipe Platform

Платформа для шеринга рецептов и планирования меню.

## Возможности

- Кулинары публикуют и редактируют рецепты
- Шеф-редакторы модерируют рецепты
- Система пересчитывает ингредиенты под количество порций
- Генерация списка покупок на основе рецепта

## Стек

PostgreSQL, Redis, REST API, веб-интерфейс
